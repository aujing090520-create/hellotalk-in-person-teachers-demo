# 6420-002｜线下教师 Profile 调整：竞品研究与方案

## 研究结论

专业身份不能只靠“老师帽”图标表达。有效的信任信号应拆成三类，并全部复用线上课程页已存在字段：

1. **资格**：已有的“平台老师”标识；
2. **履约**：已有的上课次数、学生人数与好评率；
3. **线下可达性**：可选择的公开 POI、时间与课程，而不是老师当前位置。

## 公开竞品信号

| 产品 | 已观察做法 | 对本需求的启发 |
| --- | --- | --- |
| Preply | 将“认证教学资格”和“近期平台表现”分为 Professional Tutor / Super Tutor 两类标识；证书放在排期附近展示。 | “认证面授老师”应是明确的资格标，不要与 VIP、等级、活跃等混在一起。 |
| Airbnb Services & Experiences | 对服务提供者的经验、教育、证书、评价与场所适配性进行审查；地图位置验证只证明地点，不外推到其他描述。 | 将地点定义为“已核验 / 老师设定的可选上课地点”，而不是定位或住址。 |
| Superprof | 将验证资料、学历、学生评价与可用性作为教学信任组合。 | 线下教师首页需先显示“能力 + 可约 + 地点”，个人兴趣和学习连胜退到后面。 |

## 推荐方案（待设计确认）

### 先做减法：教师模式的信息白名单

首屏只回答四个问题：**是不是可信老师、教什么、在哪里上、怎么买**。以下是明确取舍：

| 现有信息 | 决定 | 原因 |
| --- | --- | --- |
| 顶部“附近人数” | 删除 | 与老师课程质量、地点和预约无关，且会让地图误读为社交附近页。 |
| 点赞数 | 删除 | 不是课程信任信号；如保留，应只在动态页出现。 |
| VIP、等级 | 从教师首屏删除 | 是平台权益 / 游戏化信息，不构成教师资质。 |
| 性别、年龄 | 从教师首屏删除 | 对选择课程没有直接帮助，也会稀释职业身份；只在个人档案中保留。 |
| 7 门语言与星级 | 收敛 | 首屏只展示“教学：中文”和最多两门辅助沟通语言；完整语言能力移至个人档案。 |
| 连胜、加入天数、学习点数 | 下沉到个人档案 | 是社交学习履历，不应出现在付费课程决策路径。 |
| 兴趣标签 | 下沉到个人档案 | 只服务社交破冰，不服务课程筛选。 |
| 视频介绍 | 保留但折叠 | 有助于判断教学风格；不应抢占首屏或地点轮播。 |
| 平台老师、上课次数、学生人数、好评率 | 保留 | 已有的、直接有效的教学信任信息。 |
| 课程、评价、可选地点 | 保留并前置 | 是面授下单必需信息。 |

课程不是新的主 Tab，而是教师模式下固定前置的交易区。保留原 Profile 的分栏骨架，改为 `个人档案 / 动态 / 评价`：评价替换原“荣誉”，动态继续保留；课程不在 Tab 内，始终位于分栏上方。

### A. 顶部地图改为「可选上课地点」轮播

- 顶部大图只展示老师为当前课程设定的公开 POI；每页一个地点，最多 3 页。
- 地图按地点周边缩放，而不是深圳 / 香港的大区域缩放；不展示老师实时位置或精确私密住址。
- 每页包含：`地点名称`、`区 / 地铁或地标`、`可上课课程数`、`最近可约时间`。
- 右下角显示 `1 / 3` 与分页点；左右滑动或点按页签切换，默认不自动轮播。
- 点击地图或地点信息，打开当前老师筛选后的课程 / 地点抽屉；抽屉内仅展示该老师课程及其可选地点。
- 若只设 1 个地点，隐藏分页但保留地图；若暂无可约地点，不显示这一区域，也不以“附近人数”替代。

### B. 身份区改为「专业教师身份」

- 头像边框左上增加 **小型教学资格章**（盾牌 + 书本 / 勾），而非毕业帽。毕业帽会把“认证老师”误读成学生或校园属性。
- 昵称下新增单独一行：`认证面授老师 · 中文口语`；它是身份，而非可点击标签。
- VIP、等级、性别从昵称旁收敛到次级信息位，避免与教师资质争夺视觉优先级。
- 头像下不重复贴地点；首屏由顶部地点轮播承担线下地点信息。

### C. 首屏信息顺序（不新增字段）

1. 地点轮播地图（线下价值）
2. 头像、昵称、认证面授老师、资质摘要（信任）
3. 既有信任数据条：`77 上课(次) · 17 学生(个) · 好评率 100%`；仅在“平台老师”身份下展示。
4. 教学语言、教学类型与已有的视频介绍；视频可折叠，不抢占地点轮播的首屏空间。
5. 和我一起上课（课程与价格）；卡片点击进入课程详情 / 地点选择。
6. `个人档案 / 动态 / 评价` 分栏；评价承接已有课程评价列表，个人档案承接兴趣与语言学习数据。

可复用字段映射：

| Profile 展示 | 已有线上字段 |
| --- | --- |
| 平台认证老师 | 平台老师标识 |
| 教学成果 | 上课次数、学生人数、好评率 |
| 擅长什么 | 教学语言、教学类型标签、个人介绍 |
| 是否能信任与购买 | 视频介绍、课程列表、课程评价 |

### D. 约束与状态

- 地点可见范围以 POI 为准；不展示住址、实时位置或精确坐标。
- “认证”复用既有“平台老师”审核状态；“地点已核验”与“老师身份认证”分开，不能互相替代。
- 多门课共用同一地点时，顶部按地点去重；点击后在抽屉内展开该地点的多门课程。
- 老师可设 1–3 个地点；地点下架、课程失效或当前城市不匹配时不进入轮播。

## 不建议

- 不把毕业帽直接压在头像正上方：识别弱且显得游戏化。
- 不延续当前“深圳—香港”大范围地图：它展示城市关系，不能帮助用户判断上课便利性。
- 不将“平台老师”“认证老师”“VIP”“等级”都做成同权重彩色胶囊：会稀释专业身份。
