# 附近面授老师 Demo

## 启动

```bash
npm run dev
```

浏览器访问 `http://127.0.0.1:4173`。

## 覆盖路径

- 深圳（5 位符合条件老师）：附近页展示面授老师模块。
- 点击老师头像：进入对应认证老师的 Profile。
- 点击“更多”：打开全局面授地图；可切换有课城市、按可约时间与课程语言筛选、点击地图点位或课程卡。
- 从老师 Profile 点击地点：打开老师聚焦地图；仅展示该老师在当前城市的在售线下课程与地点，不显示城市切换或全局筛选。
- 广州（3 位符合条件老师）：附近页不展示模块。
- 控制台语言仅用于本地 Demo 验证，不属于产品端需求。
